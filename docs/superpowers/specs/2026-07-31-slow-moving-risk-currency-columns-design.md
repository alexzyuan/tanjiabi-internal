# 滞销处置周报：人民币展示与独立指标列设计

## 目标

将“动销预警”表格中以 `/` 合并展示的复合指标拆为独立列，并把金额默认按人民币展示。日常预警新增“店铺原币种”筛选，用于筛选 USD、CAD 等站点原币种；筛选不改变人民币展示口径。

## 表格列

现有复合列拆分为以下独立列，并继续由共享 `data-table-manager` 管理宽度：

| 复合列 | 拆分后的列 |
| --- | --- |
| 店铺 / 站点 | 店铺、站点 |
| 当前可售 / 90天+ | 当前可售、90天+库存 |
| 库存金额 / 90天+ | 库存金额（人民币）、90天+库存金额（人民币） |
| 可售天数 / 30日转化 | 可售天数、30日转化 |
| 30日销量 / 毛利 / 均毛利 | 30日销量、30日毛利（人民币）、30日均毛利（人民币） |
| 广告花费 / 占比 / ACOS | 广告花费（人民币）、广告占比、ACOS |
| 清仓 / 清算回收 | 清仓回收（原币）、清算回收（原币） |

原币回收情景保留原币展示，因为清仓价 9.9 与清算价 1 是用户定义的原币处置情景；表格增加“原币种”列，以便与人民币金额区分。

## 数据与汇率

`slowMovingRiskService` 使用领星订单利润接口的 `currencyCode=CNY` 读取 30 日利润与广告金额；FBA 库存金额继续使用领星库存明细中的人民币金额/成本字段。为每行保留并暴露：

- `currencyCode`：店铺原币种；
- 人民币金额字段：库存金额、90天+库存金额、30日毛利、30日均毛利、广告花费、资金风险金额；
- 原币金额字段：清仓回收、清算回收、移除费（可计算时）。

人民币口径由领星接口直接返回，不在 BI 内维护静态汇率或进行本地换算。原币种仅用于店铺筛选和原币处置情景标签：优先读取领星记录中的币种字段；记录未提供时，按店铺/站点的已知市场币种补齐。若店铺币种无法识别，实时数据请求以 `currency` 数据源错误失败，不允许错误归类到其他币种。

## 筛选与接口

日常预警筛选栏新增原生单选下拉框“币种”。后端 `GET /api/dashboard/slow-moving-risk/live` 接收 `currencyCode`，服务层在汇总行上按该字段过滤。筛选选项从全部行的 `currencyCode` 去重生成。

周报与历史周报是冻结快照，不追加筛选控制；但其表格使用同一套拆分列与人民币展示。

## 模块归属

- `src/services/slowMovingRiskService.js`：金额币种建模、人民币换算、币种筛选和筛选选项。
- `src/services/inventoryProvisionService.js`：从领星库存源规范化原币种、行级汇率和金额字段。
- `routes/inventory.js`：透传 `currencyCode` 查询参数。
- `assets/js/features/slow-moving-risk.js`：独立列渲染、币种筛选查询与筛选选项。
- `index.html`：筛选控件、语义列头和稳定列键。
- `assets/css/pages/26-slow-moving-risk.css`：仅在需要时添加本页面列展示规则；共享表格宽度不在页面 CSS 固定。

不修改快照调度、风险阈值、处置规则、FBA 移除费规则或其他业务页面。

## 错误处理与可观测性

对于领星生产数据，任意 SKU 无法识别店铺原币种时，会以 `currency` 数据源错误失败，不返回筛选口径不完整的周报。错误日志记录 SKU、店铺、币种和缺失字段，不记录凭据。

本地 mock 数据使用明确的 `CNY` 币种，使页面可被开发与浏览器测试验证。

## 验证

1. 服务测试验证 CNY 订单利润请求、店铺原币种识别失败、币种过滤和筛选选项。
2. 路由测试验证 `currencyCode` 透传。
3. 前端测试验证独立列、币种筛选请求和无组合表头。
4. CSS/表格结构测试验证稳定 `data-column-key` 与生成样式。
5. 浏览器验证生产样式下的桌面和窄屏：页面不横向溢出、表格容器可横向滚动、币种筛选可用。

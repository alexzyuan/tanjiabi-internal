# 运费看板设计

## 目标

在 BI 的物流板块新增 `运费看板`，作为 FBA 货件转发货单时写入领星物流费用的数据源。第一版由团队在 BI 内手填维护，不依赖领星接口或外部表格。

## 数据字段

表格字段按页面顺序为：

1. 周数
2. 日期
3. 国家
4. 仓库代码
5. 承运商
6. 运输方式
7. 价格

`周数`由 `日期`自动生成，使用 ISO 周格式 `YYYY-Www`，页面不允许手动编辑周数。

`承运商`第一版限定为 `九方通逊`、`同袍`，新增行默认 `九方通逊`。

`运输方式`第一版限定为 `普船`、`快船`、`空运`、`快递`。

## 存储与校验

后端使用本地 JSON 文件 `data-cache/freight-rates.json` 保存数据。写入必须校验日期、国家、仓库代码、承运商、运输方式和价格；价格必须是非负数字。

同一 `周数 + 国家 + 仓库代码 + 承运商 + 运输方式` 只能存在一条记录，避免后续转发货单匹配运费时出现歧义。

## 页面行为

页面在 `物流` 导航下新增子板块 `运费看板`。表格按周分组展示，每周前显示一行分割标题。用户可以新增、编辑、删除记录。保存失败时直接显示后端错误，不做静默兜底。

## 后续匹配规则

后续 FBA 货件转发货单时，系统用 `国家 + 仓库代码 + 承运商 + 运输方式 + 周数` 匹配一条运费记录，再把价格写入领星发货单的物流费用字段。

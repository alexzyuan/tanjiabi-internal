# 预算目标筛选与导入弹窗

## 2026-08-08 交互契约更新

- 预算页面改为单一月份筛选控件，默认使用当前月份；不再显示“未选择月份，默认显示全部”提示，也不再提供“添加月份”按钮或月份芯片。
- 导入弹窗新增必选的国家和店铺选择，并按国家联动店铺；链接负责人字段从弹窗移除，不再作为导入必填项。
- 上传人由服务端从当前登录账号写入 `uploadedBy`，前端不得通过请求体伪造上传人；上传记录和解析摘要均保留该审计字段。

## 目标

整理预算目标页面的上传入口，移除页面内常驻上传面板。页面筛选栏仅保留月份、平台、国家、店铺、链接负责人和关键词；通过独立的“导入预算”按钮打开导入弹窗。

导入时，用户必须选择预算月份、国家和店铺。链接负责人继续作为页面筛选项，但不属于导入弹窗上下文；工作簿中的 `SKU负责人` 和历史 `skuOwner` 仍按原规则用于明细负责人筛选。

## 页面结构

预算目标视图继续由 `index.html` 承载结构，`assets/js/features/budget-targets.js` 承担页面状态、筛选、弹窗事件、上传请求和表格渲染。`app.js` 只保留既有 feature 装配。

筛选栏顺序固定为：月份、平台、国家、店铺、链接负责人、关键词、查询、重置、导入预算。国家和店铺复用现有共享国家-店铺筛选规则，避免预算页另行维护选项和联动状态。

“导入预算”弹窗使用语义化 `<dialog>`，包含：标题、关闭按钮、预算月份原生月选择控件、国家选择、店铺选择、模板下载链接、`.xlsx` 文件选择/拖放区、上传状态、取消按钮和确认导入按钮。弹窗可通过 Esc、关闭按钮和取消按钮关闭；提交期间按钮保持禁用，失败信息直接展示，不能吞掉 API 错误。

## 数据流

前端将 `budgetMonth`、`country`、`storeName`、文件名和 Base64 文件内容提交至现有预算上传 API。服务端从当前会话写入 `uploadedBy`，忽略客户端同名字段。解析器以选择的国家和店铺作为该次导入的归属；Excel 自带 `SKU负责人` 原样保留。历史预算保持可读，负责人筛选回退到其原有 `skuOwner`，不得猜测或回填新的负责人。

模板下载由受会话保护的预算 API 动态生成 `.xlsx`。模板包含解析器支持的标准摘要页和销售预算明细页、必填表头以及一行示例；不依赖生产上传目录中的历史文件。

预算筛选器以 `listingOwner` 筛选 MSKU 明细。店铺汇总行显示负责人集合，避免在一个店铺预算含多名负责人时丢失信息。销售复盘仍通过领星 Listing 映射负责人，不以预算文件负责人覆盖领星真实负责人。

预算唯一性规则保持独立：同一店铺和月份存在两份已解析预算时，预算服务必须报出包含冲突文件名的完整性错误，不能将两份预算合并成重复明细。

## 样式与可访问性

样式仅修改 `assets/css/*` 源文件，使用既有 Spectrum 语义 token、按钮和表单控件模式；运行 `npm run build:css` 生成 `styles.css`。不在页面样式中添加表格列宽规则。

桌面布局将“导入预算”作为筛选栏的明确命令；窄屏下筛选控件换行，按钮不挤压输入内容。文件区域可使用鼠标、键盘和拖放；原生控件保留可见标签和 `:focus-visible`。

## 验证

1. 先增加服务测试：缺少负责人拒绝上传，成功上传后摘要及每条 MSKU 均带有该负责人。
2. 增加前端结构/行为测试：筛选项、导入入口、语义化弹窗与负责人请求字段均存在。
3. 运行聚焦测试、`npm test`、`npm run check`。
4. 使用本地服务进行桌面和窄屏浏览器验证：页面可加载，筛选项可操作，弹窗可通过打开、Esc、取消关闭，选中文件后确认请求包含月份和负责人；检查控制台无相关错误。

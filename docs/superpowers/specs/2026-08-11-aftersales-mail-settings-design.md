# JM 售后邮箱授权设置设计

日期：2026-08-11

## 目标

让系统管理员在 BI 的“设置 → 同步中心”安全管理 `jmcustomer@163.com` 的售后邮箱开关与 163 IMAP/SMTP 授权码，避免授权码轮换后必须登录服务器修改配置。

## 范围

- 整个“设置”导航组及同步中心仅系统管理员可进入。
- 同步中心新增“JM 售后邮箱授权”卡片，仅系统管理员可查看、测试和保存。
- 现有站外售后邮箱收件、已发送箱关联、ERP 内回复和巡检逻辑保持不变。

不包含：多邮箱管理、修改邮箱账号/服务器地址/端口、发送测试邮件、变更钉钉提醒策略。

## 权限模型

前端将设置导航组和同步中心对非系统管理员隐藏；若非管理员仍使用旧链接或直接调用 API，服务端必须拒绝。

以下同步中心管理接口改为 `admin` 权限：同步状态、领星店铺、手动同步、店铺巡检状态/设置/报告/手动执行及 ERP 邮件状态更新。公共 `/api/health` 保持不变，仅用于健康检查。

邮箱设置接口全部使用 `admin` 权限。浏览器侧的隐藏仅改善界面，不作为安全边界。

## 邮箱设置行为

卡片固定展示账号 `jmcustomer@163.com`，并展示：

- 启用开关；
- 授权码是否已配置；
- 最近一次协议验证结果与时间；
- 最近一次保存或开关操作的操作者和时间。

授权码输入框为密码字段，读取配置时绝不返回旧授权码或其可逆形式。

“测试连接”使用当前输入的授权码；若输入为空，使用当前已保存的授权码。测试同时验证 IMAP `imap.163.com:993` 与 SMTP `smtp.163.com:465`，不发送邮件、不触发巡检、不更改配置。

保存启用状态时：

1. 启用且提交了新授权码时，先对候选码做 IMAP/SMTP 验证。
2. 验证成功后，以原子写入更新 `.env` 中 `AFTERSALES_MAIL_ENABLED` 和 `AFTERSALES_MAIL_PASSWORD`。
3. 重新加载运行时环境，使后续同步和发信立刻使用新值。
4. 验证失败时，不覆盖现有配置。
5. 关闭时仅写入启用状态；已保存授权码保留，但同步和 ERP 发信立即停用。

## 数据与审计

`.env` 是授权码的唯一持久化位置。服务层以受限权限原子写入它，保留文件权限。

在 `data-cache` 保存不含密钥的操作审计：操作类型、操作者、时间、结果和可展示的错误摘要。API 与日志不得记录授权码。

## 结构

- `index.html`：同步中心的语义化卡片及具名输入/按钮。
- `assets/js/features/sync-center.js`：邮箱状态加载、保存、协议测试和状态渲染；不承担凭据持久化或权限判定。
- `assets/js/features/auth-shell.js`：扩展设置导航组/视图的系统管理员可见性，并将非管理员从已打开的同步中心送回首页。
- `src/services/aftersalesMailSettingsService.js`：配置脱敏读取、候选协议测试、原子 `.env` 写入、运行时配置重载及无密钥审计。
- `src/config/index.js`：提供受控的 `.env` 重新加载能力，供设置服务在写入后调用。
- `routes/core.js`、`server.js`：注册系统管理员专用邮箱设置 API，`server.js` 只负责依赖装配。
- `routes/sync-store-inspection.js`：把设置板块管理路由由 `session` 收紧为 `admin`。

不修改 `app.js` 以外的启动业务逻辑；若需新增前端依赖，仅由 `app.js` 注入同步中心特性。

## API

- `GET /api/admin/aftersales-mail-config`：返回脱敏状态和审计摘要。
- `POST /api/admin/aftersales-mail-config/test`：测试当前或候选授权码。
- `PUT /api/admin/aftersales-mail-config`：保存开关，或保存并启用已经通过测试的新授权码。

所有接口都要求 `admin`。响应仅包含 `passwordConfigured`，绝不包含授权码。

## 验证

- 服务单测：脱敏返回、关闭不删除授权码、候选码失败不覆盖、成功后立即生效、审计无密钥。
- 路由安全测试：子账号/主账号访问设置和邮箱管理 API 返回 403，系统管理员可访问。
- 前端结构/行为测试：设置组及邮箱卡片遵循权限可见性，密码字段不预填。
- 全量 `npm test` 与 `npm run check`。
- 浏览器验证：系统管理员可打开、测试、保存开关；非管理员看不到设置且直接请求被拒绝；桌面和窄视口无溢出或控制台错误。

# 预算筛选范围收敛

## 目标

预算目标页面的筛选入口只允许用户选择德国、美国、加拿大、澳洲，以及这四个国家的预算店铺；默认表格数据也只展示这四个国家。历史巴西、墨西哥等预算文件保留在服务器上，但不删除且默认隐藏。

## 固定选项

### 国家与店铺

国家目录固定为：德国、美国、加拿大、澳洲。

店铺目录来自现有共享店铺映射，并保留：

- 德国：欧洲-探嘉德国店铺
- 美国：探嘉美国、坦蛋伯美国
- 加拿大：探嘉加拿大、坦蛋伯加拿大
- 澳洲：探嘉澳洲、坦蛋伯澳洲

上传弹窗与顶部筛选使用同一份目录；选择国家后，店铺只显示该国家的店铺。

### 销售平台

顶部销售平台筛选固定显示“亚马逊”和“沃尔玛”，提交给现有数据过滤逻辑的值分别为 `Amazon` 和 `Walmart`。不再显示 Tik Tok。

### 链接负责人

顶部链接负责人筛选固定显示“林芃”和“熊丹轩”，不再从已上传 MSKU 行动态增加其他负责人。

## 默认数据范围

国家筛选处于“全部国家”状态时，前端内部使用固定四国集合过滤预算店铺汇总和 MSKU 明细。因此历史上传记录中的巴西、墨西哥等国家不会出现在默认表格，也不会出现在国家/店铺筛选选项中。

用户选择一个或多个允许国家后，店铺筛选继续按选中国家联动；清除国家选择恢复四国默认范围。平台和链接负责人未选择时不额外缩小四国范围，选择后按固定值过滤。

后端 `listBudgetTargets()` 返回的 `shopOptions` 同样只包含四国目录，避免上传弹窗或其他前端调用重新引入被排除的国家。历史预算行仍完整返回给需要审计的后端服务，不在存储层删除或改写。

## 归属与验证

- 共享目录归属 `src/data/budgetShopCatalog.js`；预算筛选状态与默认范围归属 `assets/js/features/budget-targets.js`；页面初始选项归属 `index.html`。
- 增加目录测试，验证仅四国店铺；增加前端行为测试，验证默认过滤隐藏巴西/墨西哥以及负责人、平台固定选项。
- 浏览器验证预算页顶部筛选和导入弹窗的选项、国家店铺联动、默认表格范围及下拉菜单宽度。
- 不修改上传文件、历史摘要和其他业务页面的店铺目录。

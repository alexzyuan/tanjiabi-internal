# 店铺巡检低库存费强调提示设计

## 目标

将店铺巡检日报中每个店铺的低库存费 MSKU 行改为红色加粗提示，明确说明已产生附加费并要求及时关注。

## 范围

仅修改 `src/services/storeInspectionService.js` 的店铺日报文案。低库存费行有 MSKU 时输出：

```markdown
- <font color="#D7373F">**本周低库存费 MSKU：FEE-2、FEE-1，已产生附加费，请及时关注。**</font>
```

MSKU 的现有顺序和去重规则保持不变。没有低库存费 MSKU 时，仍不输出该行。

不改动低库存费筛选口径、巡检总状态、钉钉 @ 策略、页面 KPI/明细或其他日报模块。现有 Markdown 报告测试将断言该格式，确保文案与强调语义不会回退。

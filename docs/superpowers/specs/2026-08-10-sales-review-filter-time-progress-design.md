# 销售复盘筛选栏时间进度设计

## 目标

在销售复盘筛选栏中，将当前筛选周期的时间进度显示在日期范围与币种之间，方便与 MSKU 销量达成率直接对照。

## 范围与归属

- `index.html` 负责在 `#sales-global-filters` 内声明只读时间进度信息块，位置固定在日期控件之后、币种控件之前。
- `assets/js/features/sales-dashboard.js` 负责在加载销售复盘数据后，从同一份 KPI 数据中的“时间进度”更新信息块；数据不可用时明确显示 `-`。
- `assets/css/pages/22-sales-dashboard.css` 负责该销售页专属信息块的样式；使用现有语义令牌，不修改共享筛选控件基线。
- `app.js`、接口路由和 KPI 卡片结构不纳入本次修改。

## 交互与视觉

- 信息块是只读的，不可点击、不参与筛选，也不新增请求。
- 显示两行：标题“时间进度”和百分比值，例如 `29.03%`。
- 高度与筛选控件一致；标题与数值均在边框内，容器隐藏文本溢出并限制行高，禁止文字跨出方框。
- 使用蓝色浅底与语义蓝色文字，使其是参考指标而非可编辑控件。
- 窄屏不压缩日期范围文本；筛选栏维持既有横向滚动行为，信息块保持完整宽度。

## 数据与异常

- 复用销售复盘现有 `data.kpis` 中标题为“时间进度”的数值，避免增加接口字段或重复计算。
- 缺失、空值或非数值时显示 `-`，不使用静默补零。

## 验证

- 结构测试断言信息块位于日期与币种控件之间，并具备可供模块更新的稳定 ID。
- 功能测试断言 KPI 时间进度会更新显示，缺失值显示 `-`。
- CSS 测试断言高度、溢出限制和语义令牌。
- 浏览器检查桌面与窄屏：日期、时间进度、币种的文字均留在容器内；筛选与键盘操作不受影响；无控制台错误。
